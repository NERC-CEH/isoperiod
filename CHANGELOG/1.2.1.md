# 1.2.1

A patch release with no changes to the library. It is the first release published to [PyPI](https://pypi.org/project/isoperiod/).

## Installation

isoperiod can now be installed from PyPI:

```bash
pip install isoperiod
```

or with uv:

```bash
uv add isoperiod
```

Installing from the git repository still works, but is no longer needed.

## Packaging

- Each release merged to `main` is now built and published to PyPI automatically, using trusted publishing.
- Package metadata now includes keywords and classifiers for the supported Python versions (3.12 and 3.13) and for
  the bundled type hints (`Typing :: Typed`).
- The README links to `LICENSE` and `CITATION.cff` are now full URLs, so they work on the PyPI project page.

## Documentation

- The installation guide now installs from PyPI instead of the git repository.
